บทที่ 2 นิวรอนและฟังก์ชันกระตุ้น

หน่วยคำนวณที่เล็กที่สุดของเครือข่าย: รับตัวเลข คูณ บวก แล้ว "งอ"

🎯 วัตถุประสงค์การเรียนรู้ เมื่อจบบทนี้ คุณควรทำสิ่งต่อไปนี้ได้
  1. คำนวณผลลัพธ์ของนิวรอน y = f(w·x + b) จากตัวเลขที่กำหนดได้
  2. อธิบายได้ว่า weight และ bias ทำให้เส้นแบ่งหมุนและเลื่อนอย่างไร
  3. เปรียบเทียบรูปกราฟและความชันของ Step, Sigmoid, ReLU และ SiLU ได้
  4. อธิบายได้ว่าทำไมเครือข่ายที่ไม่มี activation จะยุบรวมเหลือฟังก์ชันเชิงเส้นชั้นเดียว
  5. บอกได้ว่า YOLO11 ใช้ activation อะไร และใช้ตรงไหน

ทบทวนความรู้เดิม

ในบทที่ 1 คุณเห็นแล้วว่าภาพหนึ่งภาพถูกเปลี่ยนเป็น tensor (1, 3, H, W) ที่มีตัวเลข 0–1 นับแสนตัว บทนี้ถามต่อว่า ตัวเลขพวกนั้นถูกนำไป "คิด" อย่างไร คำตอบเริ่มจากหน่วยคำนวณเล็ก ๆ ที่เรียกว่า นิวรอน (neuron) YOLO11-seg ทั้งตัวก็คือการนำนิวรอนจำนวนมหาศาลมาต่อกันเป็นชั้น ๆ เพื่อให้เห็นภาพ บทนี้จะใช้ตัวเลขจากภาพผลไม้ในตะกร้าของบทที่ 1 เป็นอินพุต

2.1 นิวรอนหนึ่งตัวทำอะไร

สมมติเราอยากให้คอมพิวเตอร์ตอบว่าพิกเซลหนึ่งเป็น "แอปเปิลแดง" หรือไม่ โดยดูจากค่าสีเพียงสองค่าคือ R และ G (ค่า 0–1 จากบทที่ 1) นิวรอนทำงานเป็น 3 จังหวะ

  1. คูณด้วยน้ำหนัก (weight, w) น้ำหนักบอกว่าอินพุตแต่ละตัว "สำคัญแค่ไหน และไปทางไหน" w₁ = 4 (บวก) แปลว่า R ยิ่งมากยิ่งน่าจะใช่ ส่วน w₂ = −5 (ลบ) แปลว่า G ยิ่งมากยิ่ง ไม่ น่าใช่
  2. รวมกันแล้วบวกค่าไบแอส (bias, b) ได้ผลรวมถ่วงน้ำหนัก (weighted sum) z = w₁x₁ + w₂x₂ + b ไบแอสเปรียบเหมือน "เกณฑ์" ที่บอกว่าต้องมีหลักฐานมากแค่ไหนจึงจะเริ่มตอบว่าใช่
  3. ผ่านฟังก์ชันกระตุ้น (activation function, f) เปลี่ยน z เป็นผลลัพธ์ y ในรูปนี้ใช้ sigmoid ซึ่งบีบค่าให้อยู่ระหว่าง 0 ถึง 1 จึงอ่านเป็น "ความมั่นใจ" ได้

เขียนสั้น ๆ ได้ว่า y = f(w·x + b) โดย w·x คือการคูณทีละคู่แล้วรวมกัน (dot product) สิ่งที่โมเดล "เรียนรู้" มีแค่ค่า w และ b ทั้งหมดเท่านั้น ส่วนวิธีเรียนรู้จะอยู่ในบทที่ 3–4

มองแบบภาพ: นิวรอนหนึ่งตัวคือ "เส้นแบ่ง"

ถ้านำพิกเซลหลายจุดมาวางบนกราฟ แกนนอนเป็น R และแกนตั้งเป็น G จุดที่ทำให้ z = 0 พอดีจะเรียงกันเป็น เส้นตรง จุดฝั่งหนึ่งของเส้นได้ z > 0 (ตอบว่าใช่) อีกฝั่งได้ z < 0 (ตอบว่าไม่ใช่) การเปลี่ยน w จะ หมุน เส้น และการเปลี่ยน b จะ เลื่อน เส้น ลองดูในซิมมูเลชั่นด้านล่าง

ซิมมูเลชั่น 2.1 นิวรอนตัวเดียวแบ่งพิกเซลผลไม้

ลองปรับ w₁, w₂, b ให้เส้นแบ่งแยก ● (ใช่) ออกจาก ✕ (ไม่ใช่) ให้ได้ครบทุกจุด แล้วสลับไปโจทย์ "ส้ม" และสังเกตว่ายังทำได้หรือไม่

โจทย์:

ข้างในนิวรอน (ชี้หรือแตะจุดบนกราฟเพื่อเปลี่ยนพิกเซล)

👀 สิ่งที่ควรสังเกต
  • จุดแต่ละจุดคือพิกเซลจริงจากภาพผลไม้ในตะกร้า ระบายด้วยสีจริงของพิกเซลนั้น พิกเซลของผลไม้ลูกเดียวกันจึงกระจายเป็นกลุ่ม ไม่ได้อยู่จุดเดียว (เหมือนที่เห็นในซิม 1.1)
  • ลูกศรตั้งฉากกับเส้นชี้ไปทางฝั่ง "ใช่" ทิศของลูกศรคือ (w₁, w₂) การเพิ่ม w₁ จึงหมุนลูกศรไปทาง R มากขึ้น ส่วน b เลื่อนเส้นโดยไม่หมุน
  • สีพื้นหลังที่ไล่ระดับคือค่า sigmoid ยิ่งไกลจากเส้นยิ่งมั่นใจ ลองคูณ w ทุกตัวและ b ด้วยค่าเดียวกันให้ใหญ่ขึ้น เส้นไม่ขยับ แต่ขอบจะคมขึ้น
  • โจทย์ส้มทำไม่ได้ครบด้วยเส้นตรงเส้นเดียว เพราะส้มอยู่ ตรงกลาง ระหว่างแอปเปิลแดง (G ต่ำ) กับกล้วย (G สูง) ต้องใช้สองเส้นหนีบไว้ คือต้องใช้นิวรอนหลายตัว (หัวข้อ 2.3)
🤔 ลองคิดก่อน: ถ้าตั้ง w₁ = w₂ = 0 นิวรอนจะตอบอะไร z = b ทุกจุด นิวรอนตอบค่าเดียวกันหมดไม่ว่าสีจะเป็นอะไร ถ้า b > 0 ตอบ "ใช่" ทุกพิกเซล ถ้า b < 0 ตอบ "ไม่ใช่" ทุกพิกเซล นิวรอนจะแยกแยะอะไรได้ก็ต่อเมื่อมี weight ที่ไม่เป็นศูนย์

2.2 ฟังก์ชันกระตุ้น 4 แบบ

ฟังก์ชันกระตุ้นรับ z (ซึ่งมีค่าได้ตั้งแต่ลบมาก ๆ ถึงบวกมาก ๆ) แล้วแปลงเป็นผลลัพธ์ y สิ่งที่ต้องดูมีสองอย่าง คือ รูปกราฟ (ผลลัพธ์เป็นแบบไหน) และ ความชัน (ถ้า z ขยับนิดหนึ่ง y ขยับเท่าไร) ความชันสำคัญมาก เพราะบทที่ 3 จะใช้ความชันบอกโมเดลว่าควรปรับ weight ไปทางไหน

ชื่อสูตรช่วงผลลัพธ์จุดเด่น / ปัญหา
Step1 ถ้า z ≥ 0, ไม่งั้น 00 หรือ 1เข้าใจง่ายที่สุด แต่ความชันเป็น 0 ทุกที่ จึงบอกไม่ได้ว่าควรปรับ weight ทางไหน ใช้เทรนไม่ได้
Sigmoid σ1 / (1 + e−z)0 ถึง 1อ่านเป็นความน่าจะเป็นได้ แต่ถ้า z ใหญ่หรือเล็กมาก กราฟจะแบน ความชันเกือบเป็น 0 (อิ่มตัว)
ReLUmax(0, z)0 ถึง ∞คำนวณเร็ว ความชันเป็น 1 ฝั่งบวก แต่เป็น 0 ทั้งฝั่งลบ นิวรอนที่ติดฝั่งลบจะหยุดเรียนรู้
SiLUz · σ(z)ประมาณ −0.28 ถึง ∞คล้าย ReLU แต่โค้งเรียบ ฝั่งลบใกล้ศูนย์ยังมีค่าและความชันอยู่ YOLO11 ใช้ตัวนี้

ซิมมูเลชั่น 2.2 สนามกราฟ activation

ลองลากจุดบนกราฟไปทางซ้ายสุดและขวาสุด แล้วสังเกตว่าความชัน (เส้นสัมผัส) ของแต่ละฟังก์ชันเป็นศูนย์ตรงไหนบ้าง

👀 สิ่งที่ควรสังเกต
  • Step: เส้นสัมผัสแบนราบทุกจุด (ความชัน 0) ยกเว้นตรง z = 0 ที่กระโดด ไม่มีจุดไหนบอกได้ว่า "ขยับ z ไปทางนี้แล้วดีขึ้น"
  • Sigmoid: ลากไป z = ±4 ความชันเหลือเพียงประมาณ 0.018 สัญญาณสำหรับการเรียนรู้จึงอ่อนมาก
  • ReLU: ฝั่งลบทั้งหมดได้ 0 และความชัน 0 ส่วน SiLU ที่ z = −1 ยังได้ −0.27 และความชันยังไม่เป็นศูนย์
  • SiLU มีจุดต่ำสุดประมาณ −0.278 ที่ z ≈ −1.28 แล้วค่อย ๆ กลับเข้าหา 0 ไม่ได้ตัดทิ้งทันทีแบบ ReLU

2.3 ต่อนิวรอนเป็นชั้น และทำไมต้องมี activation

นิวรอนตัวเดียวสร้างได้แค่เส้นแบ่งตรง ๆ หนึ่งเส้น ถ้านำนิวรอนหลายตัวมารับอินพุตชุดเดียวกัน จะได้ ชั้น (layer) และถ้านำผลลัพธ์ของชั้นหนึ่งไปเป็นอินพุตของอีกชั้น ก็จะได้ เครือข่าย (network) ชั้นที่อยู่ตรงกลางเรียกว่า ชั้นซ่อน (hidden layer)

ถ้าไม่มี activation จะเกิดอะไรขึ้น

ลองคิดด้วยอินพุตตัวเดียว x นิวรอนในชั้นซ่อนคำนวณ h = w·x + b (ไม่มี f) แล้วชั้นเอาต์พุตคำนวณ y = v·h + c แทนค่าเข้าไปจะได้ 

y = v·(w·x + b) + c = (v·w)·x + (v·b + c) = A·x + B

ผลลัพธ์ยังเป็นเส้นตรงอยู่ดี ไม่ว่าจะซ้อนกี่ชั้นหรือมีนิวรอนกี่ตัว ทุกอย่างยุบรวมเหลือ "A·x + B" ชั้นเดียว การเพิ่มชั้นจึงไม่ได้ช่วยอะไรเลย activation ที่ไม่เป็นเชิงเส้น (non-linear) คือสิ่งที่ทำให้แต่ละชั้น "งอ" เส้นได้ และการงอหลายครั้งต่อกันทำให้เครือข่ายสร้างรูปทรงซับซ้อนได้ ซิมมูเลชั่นด้านล่างให้เห็นเรื่องนี้กับตา

ซิมมูเลชั่น 2.3 สามนิวรอนรวมกันได้รูปอะไร

ลองเลือก "ไม่มี activation" แล้วกดสุ่มหรือเลื่อน slider กี่ครั้งก็ได้ แล้วสังเกตว่าเส้นดำได้รูปอะไร จากนั้นสลับเป็น ReLU แล้วกด "สร้างเนิน"

activation:  
👀 สิ่งที่ควรสังเกต
  • โหมดไม่มี activation: เส้นสีจางของแต่ละนิวรอนเป็นเส้นตรง และผลรวม (เส้นดำ) ก็เป็นเส้นตรงทุกครั้ง ตัวเลข A และ B ด้านล่างคือเส้นตรงเส้นเดียวที่ใช้แทนทั้งเครือข่ายได้
  • โหมด ReLU: นิวรอนแต่ละตัวเป็นเส้น "หักงอ" ที่จุด z = −b/w การบวกเส้นหักงอหลายเส้นเข้าด้วยกันจึงได้รูปเนิน รูปตัว V หรือขั้นบันไดได้
  • โหมด SiLU: ได้รูปคล้าย ReLU แต่มุมโค้งมน นี่คือสิ่งที่เกิดขึ้นนับล้านครั้งใน YOLO11
  • ในแผนภาพเครือข่าย เส้นยิ่งหนายิ่งมีน้ำหนักมาก สีน้ำเงินคือบวก สีแดงคือลบ
🤔 ลองคิดก่อน: ถ้าซ้อน 100 ชั้นโดยไม่มี activation จะได้ผลเหมือนกี่ชั้น เหมือนชั้นเดียว ทุกชั้นเป็นการคูณและบวก การคูณและบวกต่อกันกี่ครั้งก็ยังเป็นการคูณและบวกครั้งเดียว (A·x + B) ความ "ลึก" ของเครือข่ายจะมีความหมายก็ต่อเมื่อมี activation คั่นระหว่างชั้น

2.4 จากนิวรอนในบทนี้สู่ YOLO11

นิวรอนใน YOLO11 ไม่ได้รับแค่ R กับ G แต่ทำงานแบบเดียวกันทุกประการ คือคูณ รวม บวกไบแอส แล้วผ่าน activation ความต่างคือนิวรอนแต่ละตัวมองเฉพาะ พื้นที่เล็ก ๆ ของภาพ (เช่น 3×3 พิกเซล × ทุกช่อง) และใช้ weight ชุดเดียวกันซ้ำทั่วทั้งภาพ วิธีนี้เรียกว่า convolution ซึ่งจะเรียนในบทที่ 5

ตรวจจากโมเดล yolo11n-seg.pt จริงได้ตัวเลขดังนี้

  • มีบล็อก Conv 90 บล็อก โดย 86 บล็อกใช้ SiLU
  • อีก 4 บล็อกไม่มี activation อยู่ในส่วน attention ของบล็อก C2PSA (บทที่ 9)
  • ชั้นสุดท้ายของ Head เป็น Conv2d ธรรมดา ไม่มี activation เพราะต้องส่งตัวเลขดิบออกมา เช่น ระยะขอบกล่อง ซึ่งต้องเป็นค่าเท่าไรก็ได้
  • คะแนนของแต่ละคลาสถูกส่งผ่าน sigmoid ตอนถอดรหัสเอาต์พุต เพื่อให้กลายเป็นความมั่นใจ 0–1 ซึ่งก็คือค่า conf ที่จะเรียนในบทที่ 7
  • ทั้งโมเดลมีตัวเลขที่เรียนรู้ได้ (parameters) 2,876,848 ตัว ส่วนใหญ่คือ weight ของ convolution ซึ่งเป็นตัวเลขชนิดเดียวกับ w₁, w₂ ในซิม 2.1
ดูโค้ดจริงของบล็อก Conv (3 บรรทัด ข้ามได้) 
default_act = nn.SiLU()                                    # activation เริ่มต้น
self.conv = nn.Conv2d(c1, c2, k, s, ..., bias=False)
def forward(self, x): return self.act(self.bn(self.conv(x)))   # f(BN(w·x))

🔗 อยู่ตรงไหนใน YOLO11-seg

นิวรอนและ SiLU อยู่ ทุกที่ ตั้งแต่ Backbone, Neck ไปจนถึง Head บล็อก Conv ทุกบล็อกคือ Conv2d → BatchNorm → SiLU เมื่อเห็นกล่อง "Conv" ในผังสถาปัตยกรรมบทที่ 9 ให้นึกถึงนิวรอนนับพันตัวในบทนี้ที่ทำงานพร้อมกัน ส่วน sigmoid ปรากฏตอนปลายทาง คือขั้นถอดรหัสที่เปลี่ยนคะแนนคลาสเป็นความมั่นใจ

สรุปท้ายบท

  • นิวรอนคำนวณ y = f(w·x + b): คูณอินพุตด้วย weight, รวมกัน, บวก bias, แล้วผ่าน activation
  • ในเชิงภาพ นิวรอนหนึ่งตัวคือเส้นแบ่งตรง ๆ หนึ่งเส้น: w หมุนเส้น, b เลื่อนเส้น
  • สิ่งที่โมเดลเรียนรู้คือค่า w และ b ทั้งหมด yolo11n-seg มี 2,876,848 ค่า
  • Step ใช้เทรนไม่ได้เพราะความชันเป็น 0, Sigmoid อิ่มตัวที่ปลาย, ReLU ตายฝั่งลบ, SiLU = z·σ(z) โค้งเรียบและฝั่งลบยังมีความชัน
  • ถ้าไม่มี activation ซ้อนกี่ชั้นก็ยุบเหลือ A·x + B ชั้นเดียว activation ที่ไม่เป็นเชิงเส้นทำให้เครือข่ายงอเส้นและสร้างรูปซับซ้อนได้
  • YOLO11 ใช้บล็อก Conv = Conv2d → BatchNorm → SiLU (86 จาก 90 บล็อกใน yolo11n-seg) และใช้ sigmoid เปลี่ยนคะแนนคลาสเป็นความมั่นใจ
